# ParserFE

ISO 8583 Payment Message Parser (Java)

A command-line tool that parses binary **ISO 8583** card authorization messages and prints every field in a readable form.

Supported formats:

| Format | Length prefix | MTI | Field encoding |
| --- | --- | --- | --- |
| VISA | 4 bytes + 22-byte header | BCD | BCD numerics, EBCDIC text |
| Mastercard | 2 bytes | ASCII | ASCII |
| Way4 | 2 bytes | ASCII | BCD numerics, ASCII text |

Features:

- Primary and secondary bitmaps
- Fixed-length and variable-length (LLVAR / LLLVAR) fields
- EBCDIC to ASCII conversion
- **EMV chip data (field 55)** decoded into tags (BER-TLV)
- Way4 tagged private data (fields 46–48) and BER-TLV (field 112)
- Input as a hex text file (spaces and line breaks are ignored) or as a raw binary file
- Parsing time measurement

## Requirements

Java 11 or newer. No external libraries.

## Build

```
javac -d out src/*.java
jar cfe ParserFE.jar App -C out .
```

## Run

```
java -jar ParserFE.jar {iso-format} {filePathName} [{file-type}]

    {iso-format}   -> v (VISA) / m (Mastercard) / w (Way4)
    {filePathName} -> .txt (hex text file, default) / .bin (binary file)
    [{file-type}]  -> t (text file) / b (binary file)
```

Examples with the included samples:

```
java -jar ParserFE.jar v samples/visa_0100.txt
java -jar ParserFE.jar m samples/mc_0100.txt
java -jar ParserFE.jar w samples/way4_0100.bin
```

## Sample data

The files in `samples/` are **synthetic** and were generated by `tools/generate_samples.py`.
They use the public industry test card numbers (Visa 4111 1111 1111 1111, Mastercard 5555 5555 5555 4444)
and invented merchant, terminal and EMV values. They contain no real transaction data.

To regenerate them:

```
python3 tools/generate_samples.py
```

## Project structure

```
src/
  App.java          command line, input loading, output
  ISOMessage.java   message length, MTI, bitmap, dispatch to the format parser
  ParserVisa.java   VISA field definitions
  ParserMC.java     Mastercard field definitions
  ParserWay4.java   Way4 field definitions
  Util.java         bitmap, hex/BCD/EBCDIC helpers, EMV and TLV decoding
samples/            synthetic test messages (.txt and .bin)
tools/              sample generator
```

## Changes

- Removed all embedded message samples; added synthetic samples and a generator
- Hex input now ignores any whitespace, including line breaks
- Fixed field 112 (BER-TLV) length handling, which shifted every field after it
- Fixed Way4 field 48, tag 811 sub-field parsing
- Cleaner command-line validation and help

## BER-TLV tag reference (field 55)

```
First byte:
b8 b7 b6 b5 b4 b3 b2 b1
 0  0                      Universal class
 0  1                      Application class
 1  0                      Context-specific class
 1  1                      Private class
       0                   Primitive data object
       1                   Constructed data object
          1  1  1  1  1    See subsequent bytes
          Any other value  Tag number

Subsequent bytes:
b8 b7 b6 b5 b4 b3 b2 b1
 1                         Another byte follows
 0                         Last tag byte
    Any value > 0          (Part of) tag number
```
